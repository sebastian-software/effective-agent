# Repository Instructions

## Project language

Use US English for all project content, including issues, posts, discussions,
pull request titles and descriptions, comments, reviews, documentation, code
comments, commit messages, and release notes. Follow the
[project language policy](docs/contributor-checks.md#project-language) before
publishing or editing content. This rule governs work on Effective Agent; it
does not set the output language of the installable skills in other projects.

## Writing under the contributor's identity

Write from the contributor's first-person perspective when drafting or editing
content under their name. Do not refer to them in the third person or include
private coordination or approval conversations. Do not invent commitments,
approvals, or facts.
