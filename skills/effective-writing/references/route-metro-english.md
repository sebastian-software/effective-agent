# Route: Metro English

Use this route for short internal team communication that needs a relaxed US
professional register: Slack and chat messages, GitHub, GitLab, Linear, and
Jira comments, PR review notes, async updates, short internal announcements,
and German-to-English rewrites for team communication.

Metro English names a specific register within this discipline, not a
separate discipline.

## Read

[Metro English](metro-english.md) — voice target, rewrite rules, patterns to
avoid, per-channel presets, worked examples, and the output contract.

The long-form [nonfiction assignment contract](nonfiction-assignment.md) does
not apply here. A Slack message has no thesis, evidence register, or revision
sequence; loading it would slow the rewrite down without improving it.

## Apply

- Preserve intent, facts, names, constraints, and the decision. Shorten unless
  the user asked for detail.
- Make the ask obvious: what should happen, who is blocked, what decision is
  needed.
- Stop when a named controlled-language contract governs the artifact
  (ASD-STE100, Simplified Technical English, an adopted controlled-English
  profile). Hand that artifact to `effective-delivery` and keep the team
  message about it here.
- Return only the rewritten text by default.
