# Optional Cognitive Model Prompts

Use cognitive and neurobiological teaching models when someone asks for that
perspective or when a lens could help explore an unresolved attention, learning,
or expectation question. Select only what could change the design decision.
An ordinary interface task needs neither a neuroscience explanation nor a full
model checklist.

## Generate questions and experiments

| Lens | Question it can suggest | Possible design experiment |
| --- | --- | --- |
| Selective attention | What else competes with the task, and what happens when focus breaks? | Compare interruption and resumption with persistent task context |
| Working and long-term memory | What must someone carry between steps, and which cues are available when they need it? | Keep a prior choice visible or test guidance in the actual task context |
| Default mode network and reflective rest | Does this experience leave room to pause, reflect, and finish? | Try an optional reflection or a clear stopping point without another engagement prompt |
| Prediction and schemas | Which result does the person expect, and where might the system differ? | Ask for a prediction before an action, then observe understanding of its result |

These are hypothesis generators, not evidence that an interface causes a brain
state or that every person needs the same treatment. Keep simplified accounts
of brain networks, memory duration, and cognitive energy distinct from verified
scientific claims. Do not derive fixed timers, glucose budgets, diagnoses, or
universal capacity limits from teaching analogies. If a causal scientific claim
would decide the design, verify it against relevant primary research before
relying on it; otherwise frame the proposal as a design hypothesis.

## Judge the experience by observable outcomes

Evaluate comprehension, recovery, retained context, voluntary reflection, or
independent task use. More time can serve a chosen reflective activity; remove
unwanted administration without rushing the activity the person values. A
useful outcome or user preference can justify a design without a neurological
explanation.
