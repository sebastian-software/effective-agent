# Effective Photo Retouch

Improve the supplied shoot while keeping the people recognizable and the
photographic setting believable. Use the available Imagegen editing tool.

## Route by Intent

| User intent | Read |
| --- | --- |
| Retouch a portrait, prepare before/after proposals, or apply an approved look across a shoot | [Natural Shoot Retouch](references/route-natural-retouch.md) |

## Routing Boundaries

This skill edits existing photographs. It does not create new people or scenes,
reshape bodies, redesign clothing, or prescribe a new facial expression.
Apply a user-requested creative transformation as a separate brief instead of
silently treating it as natural retouch.

Commercial messaging and photo placement strategy belong to
`effective-marketing`; browser implementation belongs to `effective-web`.
Publishing photos to storage or enabling a CDN optimizer requires its own
destination and task authorization; using this skill alone does not authorize
either action.
