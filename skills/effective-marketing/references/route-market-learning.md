# Route: Market Learning

Use this route for win/loss work, adoption analysis, interviews, evidence
synthesis, and decisions about changing the segment, position, message, proof,
or channel.

## Read

1. [Market-facing decisions](market-facing-decisions.md) — the shared evidence
   boundary and deliverable contract.
2. [Market learning](market-learning.md) — the route's working guidance.

## Apply

Apply the shared operating rules in [Market-facing decisions](market-facing-decisions.md). In addition:

- State plainly which market-facing choice the evidence changes, and which it
  merely fails to contradict.

## Cross-links

- A finding that changes the product decision — target user, problem, scope,
  quality bar, release — goes to `effective-product`.
- A finding that changes the position or message returns to
  **Positioning** or **Messaging**.
- Funnel-level diagnosis and experiment design belong to
  **Conversion**.
- A new research program — recruitment, fieldwork, review or community mining,
  market sizing, cross-source synthesis — belongs to `effective-product`.
