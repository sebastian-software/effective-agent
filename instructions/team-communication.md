# Team communication

Before drafting reviews, approval bodies, PR or issue comments, replies, Slack
messages, or other communication to teammates, load `effective-writing` and its
Metro English route when available. Apply it by default even when the primary
task is technical; no explicit rewrite or style request is needed. Read the
route once per conversation and reuse it for later messages.

The technical or domain workflow retains facts, severity, the review decision,
and publication authority. The writing route owns natural, friendly phrasing
while preserving repository language and channel rules. Private technical
reports and machine-only output need no separate prose pass.

Resolve the former name "metro-english" to the Metro English route in
`effective-writing`.
