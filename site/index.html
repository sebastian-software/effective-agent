Index

Eight guides.
One way of working.

Each guide covers one discipline, routes your request to the right chapter, and names the guide that takes over next. Together they cover the path from the first idea to the market. Install the set, or take the one your next task needs.

Quality

Edited like a reference work.

Every guide is written, routed, and checked the way a maintained codebase is.

What “tuned for” means

In October 2026 we audited every guide against the current prompting guidance for GPT-6 and Opus 5.5: no dated scaffolds or shouting, clear routing, and verification matched to the task.

The seals are Sebastian Software’s own labels, not an endorsement by OpenAI or Anthropic. Results depend on the model, tools, and task.

Read our review approach ↗

  1. Focused context

    Short entry points route into specialist references. Print calibration or an advanced Rust topic stays out of unrelated tasks.

  2. Clear handoffs

    Eighty routing cases check that a request reaches the guide that owns it, and every guide names the neighbor that takes over.

  3. Defined behavior

    Written scenarios describe what a good answer does, from refusing invented evidence to keeping publication in your hands.

  4. Kept current

    Pushes run a reference audit, CI checks every link, and a monthly job flags browser-support and vendor facts that are due for re-verification.

Managed with DALO

Our skill manager

Pin reviewed versions, keep several agents in sync, and add the optional standing instructions when you want them.

curl -fsSL https://dalo.sh/install.sh | sh dalo init dalo target link codex dalo source add-catalog sebastian https://github.com/sebastian-software/effective-agent.git dalo source select sebastian effective-web dalo approve skill sebastian:effective-web dalo sync
Optional: add the standing instructions

Three instruction packs add conventions across tasks: request and completion, documentation truth, and team communication. Every guide works without them. Read the collection boundary.

dalo instructions enable sebastian:request-and-completion --target codex dalo instructions enable sebastian:documentation-truth --target codex dalo instructions enable sebastian:team-communication --target codex --target claude
