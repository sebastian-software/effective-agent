Why these skills exist

Expertise you can inspect.

Read the guidance, see where each discipline begins and ends, and adapt it to your team. The collection is open source under MIT or Apache-2.0.

See how we review skills →
  1. 01

    Professional depth

    Guidance spans architecture and implementation, product decisions, design review, writing, and the commercial work of growing a service business.

  2. 02

    Inspectable sources

    Read every skill and reference in the repository. Trace recommendations to the code, research, or source material behind the task.

  3. 03

    Clear ownership

    Each discipline names its remit and the neighboring skill that owns a different decision. Engineering and delivery have distinct jobs.

  4. 04

    Focused context

    Short entry points route into specialist references as needed. Print calibration, review voice, or an advanced Rust topic can stay out of unrelated tasks.

  5. 05

    Reviewable guidance

    Routing cases, behavioral scenarios, and repository checks help catch drift. Results still depend on the model, tools, task, and available evidence.

What “tuned for” means

We shape the guidance for GPT-6 and Opus 5.5: focused instructions, explicit routing, and verification matched to the task. The seals are Sebastian Software’s own labels, not certification or endorsement by OpenAI or Anthropic. Results depend on the model, tools, and task.

Optional standing instructions

Set the defaults. Keep the skills independent.

Skills help with a particular kind of work. Two optional instruction packs add conventions across tasks. Enable them separately in your agent setup; every skill works without them.

Request and completion
Honor the requested scope, preserve existing authorization, and carry the work through a truthful handoff.
Documentation truth
Keep documentation aligned with observable behavior, current implementation, and explicit uncertainty.

Both the skills CLI and DALO support selective installation. You do not need to adopt the full collection to use one skill.

01

Quick install

skills CLI

Add one skill to an agent environment that supports Agent Skills.

npx skills add sebastian-software/skills.sebastian-software.com --skill effective-web

Replace effective-web with any skill name, or pass --all.

02

Managed setup

DALO

Install DALO, initialize its configuration, link an agent target, and pin the reviewed selection.

curl -fsSL https://dalo.sh/install.sh | sh dalo init dalo target link codex dalo source add-catalog sebastian https://github.com/sebastian-software/skills.sebastian-software.com.git dalo source select sebastian effective-web dalo approve skill sebastian:effective-web dalo sync

This installs Effective Web. Add standing instructions only if you want them.

Optional: add the instruction packs

Requires a DALO release with source-backed instruction packs.

dalo instructions enable sebastian:request-and-completion --target codex dalo instructions enable sebastian:documentation-truth --target codex
